# Security

Do not commit private benchmark tasks, fixture identifiers, project IDs,
references, answer keys, verifier parameters, API keys, OAuth tokens, signing
keys, model transcripts, or unredacted execution artifacts.

The public repository accepts only capability blueprints, framework code,
synthetic test fixtures, and secret-free commitments or aggregate results.

Report a suspected credential or private-task exposure privately to the
InfobotAI maintainers. Do not open a public issue containing the material.
